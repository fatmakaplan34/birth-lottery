# Birth Lottery Frontend

React, TypeScript ve Vite ile hazırlanmıştır. Etkileşimli küre `react-globe.gl`,
ülke geometrileri ise Natural Earth tabanlı `world-atlas` verisini kullanır.

```powershell
npm install
npm run dev
```

Backend adresi `frontend/.env` içindeki `VITE_API_BASE_URL` ile değiştirilebilir.

Kontrol komutları:

```powershell
npm run lint
npm run build
```
